First public release. kcal is a macOS menu bar app that shows what your AI coding agent loads before you type, and how much of your usage limit is left. It is built for Claude Code users; Codex and Kiro are optional. It runs locally, with no kcal account and no telemetry.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/HaeDalWang/kcal/main/install.sh | sh
```

Or download `kcal-macos-universal.dmg` below. The app is not signed or notarized by Apple (ad-hoc signed only). If you open the dmg from a browser download, macOS blocks the first launch: try to open it once, then go to **System Settings → Privacy & Security → Open Anyway**. Details: [README](https://github.com/HaeDalWang/kcal#install).

Each file has a `.sha256` next to it. Check with `shasum -a 256 -c kcal-macos-universal.dmg.sha256`.

## What's in it

- Limit left per agent for the 5-hour and weekly windows, reset times, and whether you are using the limit faster than an even pace.
- Startup context: system prompt, tools, MCP servers, memory files, skills and agents, as a share of the context window. Measured once you have a Claude Code session on this Mac; an estimate before that.
- Checks that point at what you could switch off. Suggestions come from your last 30 days of Claude Code history (at least 10 sessions); kcal doesn't suggest turning off Codex or Kiro items because it can't see how often you use them. Any change shows the exact line first, keeps a backup, and has Undo.

## Known limits

- Universal binary, run on Apple Silicon only so far.
- No Windows build yet.
- The first limit check reads the `Claude Code-credentials` Keychain item. macOS may ask once; the prompt names `security`, not kcal. See [what is sent](https://github.com/HaeDalWang/kcal#privacy-and-what-it-reads).
