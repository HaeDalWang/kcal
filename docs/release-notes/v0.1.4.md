Windows build, start at login, and Codex MCP suggestions. To update on macOS, run the install line again.

```sh
curl -fsSL https://raw.githubusercontent.com/HaeDalWang/kcal/main/install.sh | sh
```

Or download `kcal-macos-universal.dmg` below. Still unsigned (ad-hoc signed only); see [Install](https://github.com/HaeDalWang/kcal#install) for the first-launch step. Check a download with `shasum -a 256 -c kcal-macos-universal.dmg.sha256`.

## New

- Windows (x64): `kcal-windows-x64-setup.exe`. Unsigned, so SmartScreen asks first: choose "More info" → "Run anyway". See [Windows](https://github.com/HaeDalWang/kcal#windows-x64) for what it reads and how to uninstall.
- Start at login: a switch in Settings, off by default.
- Codex: MCP servers you did not use in recent Codex sessions are now suggested for turning off, using the same session minimum as Claude.

## Fixed

- Windows paths: the Claude CLI is found in `~/.local/bin` and `%APPDATA%\npm`, and `\\?\` prefixes no longer show in context paths.
