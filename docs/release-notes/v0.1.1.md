Fixes and polish since the first release. To update, run the install line again.

```sh
curl -fsSL https://raw.githubusercontent.com/HaeDalWang/kcal/main/install.sh | sh
```

Or download `kcal-macos-universal.dmg` below. Still unsigned (ad-hoc signed only); see [Install](https://github.com/HaeDalWang/kcal#install) for the first-launch step. Check a download with `shasum -a 256 -c kcal-macos-universal.dmg.sha256`.

## New

- Startup context is grouped by kind, with the biggest rows first and the rest behind a disclosure.
- Settings use a macOS-style grouped screen; tuning fields are folded by default.
- Hidden Checks cards can be reviewed and brought back one at a time.
- Agent tabs show each company's mark. Cmd+D (Ctrl+D) opens the dashboard.
- Compact daily-activity card; a "pending" state for usage not counted yet (today only); quiet agents collapse.
- Codex: compressed rollouts are read.

## Fixed

- Weekly usage is counted again after an early reset that keeps the same reset time.
- Codex: `project_root_markers`, `plugins._default.enabled`, multi-line arrays, and the plugin manifest skills path are read correctly.
- MCP servers from a parent-folder `.mcp.json` and in bypass mode are counted.
- Agents installed after settings were saved are turned on.
- An agent whose limit was never read shows a dash instead of 0 %.
- Project coach writes are refused through symlinks that point outside the project; the usage API no longer follows redirects.
- Faster log parsing: each Claude log file is parsed once, Kiro sessions are memoized and listed less deeply.
- Keyboard focus moves into opened panels, Escape closes them, and focus returns to where you were.
- Clearer wording for first-run and empty states, plus Korean copy polish.
