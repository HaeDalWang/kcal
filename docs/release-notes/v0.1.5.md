Claude sessions view, claude.ai connectors in Diagnose, and saved-setting checks for Codex and Kiro. To update on macOS, run the install line again.

```sh
curl -fsSL https://raw.githubusercontent.com/HaeDalWang/kcal/main/install.sh | sh
```

Or download `kcal-macos-universal.dmg` below. Still unsigned (ad-hoc signed only); see [Install](https://github.com/HaeDalWang/kcal#install) for the first-launch step. Check a download with `shasum -a 256 -c kcal-macos-universal.dmg.sha256`. Windows: `kcal-windows-x64-setup.exe` (unsigned; SmartScreen: "More info" → "Run anyway").

## New

- Sessions (macOS): see your running Claude sessions, and stop old idle ones after you confirm.
- Diagnose: claude.ai connectors (Figma, Slack, Drive…) get one card each with how to turn them off in Claude Code. kcal never changes connector settings.
- Diagnose: project MCP servers and skills now come from your most recent work folders (5 by default; Settings → "Recent work folders to diagnose"), each labelled with its folder.
- Codex and Kiro: advice cards for saved settings worth checking (Codex: max/ultra reasoning effort, instruction files over `project_doc_max_bytes`, duplicate hooks; Kiro: tool search and auto compaction off). Advice only, nothing is changed.

## Fixed

- Claude tokens-per-% estimate uses only the last 7 days of windows, so a plan change no longer skews it.
- A settings file naming an agent this version does not know no longer resets your agent choice to all agents.
- Dashboard: "Limit not read" shows only when the usage check really found no window.
- Codex plugin skills with a `./` path are now found.
