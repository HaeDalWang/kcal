Network summary: the app contacts `api.anthropic.com` (and `chatgpt.com` if you enable Codex), by default every 5 minutes while running (Kiro: every 10 minutes through `kiro-cli`; both intervals are settings). After a rate-limit reply the interval doubles, up to 60 minutes by default, and pressing Refresh checks as well. Only agents you enable are queried (`usage/schedule.rs`: `plan`). I searched the Rust and frontend source for other URLs, HTTP clients and plugins and found none besides test fixtures and documentation links that the UI shows as plain text. The webview's Content Security Policy only allows local IPC (`src-tauri/tauri.conf.json`, `app.security.csp`). Please check this yourself: `git grep -nE 'https?://' -- src src-tauri/src`.

Start at login is OFF by default and only changes when you use its Settings switch. On macOS it writes/removes `~/Library/LaunchAgents/kcal.plist`, containing the current executable path. On Windows the underlying library writes/removes the `kcal` value under `Software\Microsoft\Windows\CurrentVersion\Run` (and may update its `Explorer\StartupApproved\Run` override); see [decision 0024](decisions/0024-login-autostart.md) for the current-user limitation. No autostart state is stored in `settings.json`, and no network request is made. Turn the switch off before uninstalling; manual Login Items or Startup-folder shortcuts must be removed separately.
