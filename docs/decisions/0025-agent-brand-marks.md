# 0025. 에이전트 표시에 회사 마크(단색)

- 상태: 채택
- 날짜: 2026-11-18
- 앞선 결정: [0004](0004-usage-and-tray.md) "상표 로고는 쓰지 않는다"(탭 아이콘 부분만 바꾼다)

## 문제

탭 아이콘은 kcal 불꽃에 C·X·K를 뚫은 모양이었다. 16px에서 글자가 뭉개져 세 탭이 같은 불꽃으로 보였다(2026-11-18 디자인 점검). 색 칸·테두리 원·색 점 초안도 사용자가 모두 별로라고 했다.

## 결정

- 탭·대시보드의 에이전트 아이콘(`agent-icon.tsx`)은 각 회사 마크(Claude·OpenAI·Kiro)를 글자색 한 색(`currentColor`)으로 그린다. 에이전트 색은 지금처럼 막대·링·그래프에만 쓴다. (사용자 선택 "E", 2026-11-18)
- 경로는 CodexBar(MIT)의 `ProviderIcon-*.svg`를 그대로 쓰고 파일 머리에 출처를 적는다. 직접 그리지 않는다.
- 메뉴바 트레이 아이콘과 앱 아이콘은 kcal 불꽃 그대로다(0004·0012).

## 위험

- 마크는 각 회사 상표다. MIT는 코드 저작권만 허락하고 상표는 허락하지 않는다. "이 값이 어느 서비스 것인지" 알리는 용도로만 쓰고(CodexBar와 같은 방식), README에 상표 안내 한 줄을 둔다. 회사가 빼 달라고 하면 이 파일 하나만 되돌리면 된다(이전 모양: 이 결정 직전 commit의 `agent-icon.tsx`).
- 각 회사 브랜드 가이드가 단색 사용을 허락하는지는 확인하지 않았다(모름).
