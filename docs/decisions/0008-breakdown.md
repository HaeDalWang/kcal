## tuning (0007 방식)

## 패리티

같은 `now`(고정 유닉스 초)에서 Rust `pattern`과 `decompose.py`의 `codex_usage`가 창 수, N·M 중앙값·p90에서 모두 같다. 기준 시각과 +10일·+12일(창 29·12·7개, 짝수 개 중앙값 3.5 포함)로 확인했다. 표와 명령: 로컬 조사 기록(비공개). Rust 쪽은 `#[ignore]` 테스트 `codex_pattern_parity_on_real_rollouts`(`KCAL_PARITY_NOW`).
