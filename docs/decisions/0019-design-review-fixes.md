- 범위: 2026-11-09 디자인 검토가 찾은 `docs/design.md` 위반 34건(D-01~D-34). 코드를 규칙에 맞추고 `design.md`는 고치지 않는다. 계산·IPC·Rust는 그대로다.

## 1단계: 모습이 바뀌지 않는 것

### 토큰 (라이트 `:root`만, 무채색이라 색상 없음)

대비는 `contrast.mjs`(WCAG 상대 휘도) 값이다.

| 토큰                 | 전                 | 후                 | 대비 전 → 후                                                          | 위반 |
| -------------------- | ------------------ | ------------------ | --------------------------------------------------------------------- | ---- |
| `--ring`             | `oklch(0.708 0 0)` | `oklch(0.668 0 0)` | 면(흰색) 위 2.59 → 3.02 (기준 3)                                      | D-02 |
| `--muted-foreground` | `oklch(0.556 0 0)` | `oklch(0.546 0 0)` | `muted`·`accent` 위 4.34 → 4.52, `muted/60` 위 4.49 → 4.69 (기준 4.5) | D-26 |

`--ring`은 포커스 때만 보인다(포커스 링·`border-ring`). `--muted-foreground`는 회색 글자 전체가 아주 조금 진해진다(`#737373` → `#707070`).

### mask 흑백 (D-32)

`agent-icon.tsx`의 `#fff`·`#000`은 SVG mask의 밝기 값(보이게·뚫기)이다. 화면에 칠하는 색이 아니라서 토큰으로 바꾸면 mask가 깨진다(토큰은 다크에서 밝기가 뒤집힌다). 4절 "새 색은 결정 기록 없이 더하지 않는다"에 따라 여기 기록하고, 코드는 이름 붙은 상수 `MASK_SHOW`·`MASK_CUT`으로 둔다.

### 용어 (D-33)

0009 "용어" 표에 지금 화면 용어 8줄을 더했다(캐시 적중률, 최근 5시간 요청, 많이 쓴 세션, 긴 세션, 큰 컨텍스트, 구성 조각, 처방 효과, 진단하기). 뜻은 0010·0013·0014·0016 문장에서 가져왔다. **사용자 확인 전**이다.

### 그 밖

- 포커스: 메뉴·chevron·설정 뒤로 버튼은 `ui/button.tsx`와 같은 링(`focus-visible:ring-3 ring-ring`)과 누를 때 `active:translate-y-px`. 버튼·탭·입력·체크박스·요일 버튼의 링은 `ring-ring/50` → `ring-ring`(불투명).
- 일요일 글자 `text-red-600 dark:text-red-400` → `text-destructive`.
- "평균" 글자: 세션 툴팁 "평균 입력" → "요청당 입력", 설정 힌트 "요청당 평균 입력" → "요청당 입력". 값과 계산은 그대로.
- 값 툴팁은 "정확: …"로 시작한다(막대 "정확: 11/05 14:00 시작 · 31%", 오늘 숫자 칸, 총 요청 수, 세션 줄).
- `tabular-nums`: "N시간 전 기준", "캐시되지 않은 요청 ~X%".
- `prefers-reduced-motion`이면 전환을 모두 끈다(`index.css` 한 블록).

## 2단계: 모습이 바뀌는 것

### 토큰 (라이트 `:root`만, 색상·채도 그대로, 밝기만)

| 토큰             | 전                    | 후                     | 대비 전 → 후 (기준 3)                                                        | 위반        |

`--agent-kiro`와 다크 토큰은 그대로다(지난 구간·링은 아래 코드 변경으로 통과: 라이트 kiro 지난 구간 2.05 → 3.73, 다크 claude 2.64 → 5.71).

토큰만으로 맞추지 않고 코드도 바꾼 곳:

- 지난 구간 막대 불투명도 0.5 → 0.85(`agent-metrics.tsx` `PAST_BAR_OPACITY`). 0.75면 토큰을 claude 0.58·codex 0.54까지 낮춰야 해서 0.85를 골랐다. 지금 구간은 색만이 아니라 막대 위 점으로도 구분한다.
- 링 트랙 혼합 30% → 12%(`activity-rings.tsx`). 30%는 토큰을 claude 0.565·codex 0.52까지 낮춰야 통과한다.
- 구성 막대 조각을 배경 대신 글자색과 섞는다(`behavior-section.tsx`). 45% 조각 대비 1.37 → 8.98.

대비 미달 조합(화면에 쓰는 것) 43 → 2. 남은 2는 요일 버튼 선택 테두리이고, 선택은 굵은 글자로 보인다(남은 문제 참고).

### 그 밖

- 카드 안 상자 테두리 제거(오늘 숫자 칸, 처방 효과 주간·처방별 줄은 `border-t`로 나눔), "기록 일부만" `rounded-md`.
- 값이 없으면 개요 다이얼을 숨긴다. 낮음은 이름 줄 "낮음" 글자 + 탭 이름 옆 경고 아이콘. 하루 몫을 넘으면 "넘침" 글자.
- 에이전트 이름 글자는 글자색 + 색 점(오늘 숫자 칸·처방 효과).
- "약 X%" → "~X%", "한 턴 ≈ 월 한도의 X%" → "질문 1번 = 월 한도의 X%", "Codex 한도 rollout" → "Codex 한도 기록 파일", 세션 배지 9 → 10px.
- 체크박스·입력칸 테두리 `border-input` → `border-ring`. `<summary>`는 메뉴와 같은 hover·포커스 링·누름(`info-section.tsx` `SUMMARY_CLASS`).
- 대시보드 에이전트 카드 안 묶음 간격 `gap-2` → `gap-3`, 2열 기준 `md:`(768) → `min-[900px]:`.
- 불러오는 중·값 없음·오류 한 벌(`state-text.tsx`, 11px, 문구 "불러오는 중…"/"값 없음").
- 선택된 요일은 글자를 굵게(500 → 700).

## 남은 문제

- 요일 버튼 선택 테두리 대비 1.39(라이트)·1.55(다크). 선택은 굵은 글자가 알린다. 테두리도 3:1로 할지는 사용자 결정.
- 진단하기 미리보기 패널을 연 순간에는 패널 확인 버튼과 점검 첫 카드 버튼이 함께 강조될 수 있다(칸 사이 상태를 올리지 않았다).
- 처방 효과 머리는 숫자 하나로 줄일 값이 없어 제목 → 설명 순 그대로다(D-30 일부).
- "기록 일부만" 툴팁은 값이 아닌 설명이라 "정확: " 형식을 붙이지 않았다(D-24 일부).
- vibrancy(반투명) 배경 위 대비는 계산하지 못했다.
- 0009에 더한 용어 8줄은 사용자 확인 전이다.
