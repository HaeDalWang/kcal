# 0011. 트레이 시각 디자인: 에이전트 색, 페이스, 다이얼

- 상태: 채택(구현함, 2026-11-05)
- 앞선 결정: [0010](0010-tray-and-dashboard.md)(트레이 구성). 구성은 그대로 두고 겉모양만 바꾼다.

## 색 토큰

`index.css`의 `:root`·`.dark`에 `--agent-claude`(테라코타), `--agent-codex`(에메랄드), `--agent-kiro`(보라), `--warn`(호박)을 둔다. `@theme inline`에서 `agent-*`·`warn` 색 클래스로 연결한다. 에이전트별 색은 `agent-metrics.tsx`의 `AGENT_COLOR: Record<Agent, string>` 하나로 막대·다이얼·탭·구간 그래프가 같이 쓴다. 남은 %가 `lowPercent` 이하면 에이전트 색 대신 `destructive`.

## 위계: 값 → 막대 → 한 줄

창마다 큰 글씨 "5시간 81% 남음"(값), 두꺼운 막대(시각), 회색 한 줄 "N% 여유 · 초기화까지 버팀"(해석) 순서. 숫자는 모두 `tabular-nums`. 지표는 2열 카드(작은 라벨, 큰 값). 구간 그래프는 에이전트 색, 지난 구간 50% 투명.

## 페이스

새 판정 상수 없이 남은 %·`resetsAt`·창 길이로 프론트(`lib/pace.ts`)에서 계산한다.

- 창 길이: 5h, 7d, 월은 `resetsAt`에서 달력 1개월 뺀 시각이 시작.
- 기대 남은 % = 100 × (1 − 경과 비율). 막대의 세로 표시선 위치.
- 차이 = 남은 % − 기대 남은 %, 반올림해 0이면 "예상 속도", 양수 "N% 여유", 음수 "N% 부족"(`--warn`색).
- 소진 예상: 사용 속도로 남은 %가 바닥나는 시간이 초기화까지보다 길면 "초기화까지 버팀", 아니면 "Xh 후 소진".
- `resetsAt` 없음·초기화 지남·경과 0이면 줄과 표시선을 숨긴다.

## 개요 다이얼

에이전트마다 카드 한 줄. 왼쪽 원형 다이얼(가장 급한 창의 남은 %), 오른쪽에 이름·갱신 시각, 가장 급한 창의 초기화까지, 나머지 창은 얇은 막대와 남은 시간.

## 메뉴 단축키

아이콘(lucide) + 라벨 + 오른쪽 단축키. 새로고침 ⌘R/Ctrl+R, 설정 ⌘,/Ctrl+, 종료 ⌘Q/Ctrl+Q. 설정 화면에서는 새로고침·설정 단축키를 무시한다.

## 레퍼런스

- CodexBar 메뉴(사용자 스크린샷): 제목, 창별 큰 값, 두꺼운 막대와 표시선, 2열 숫자 카드, 아이콘 메뉴.
- Power-xc/usage-gauge: 다이얼 카드와 브랜드색.
